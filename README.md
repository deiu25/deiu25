## Andrei Badulescu

Full-stack developer in Ploiesti, Romania. For 3+ years I have built and maintained web applications: ERP screens and reports that a factory uses every day, and Next.js products of my own. My products ship LLM features (chat with RAG, prompt scoring), and I write my own Claude Code skills.

### What I work on

- **ERP for a window and door manufacturer.** PHP and SQL Server: orders, contracts, logistics, invoicing. I moved the codebase from PHP 5.6 to 8.5 and I build its reports in SSRS and Power BI.
- **[BaseTech](https://www.basetech.ro).** Software infrastructure and automation: ERP systems, AI integrations, SaaS platforms. Next.js, TypeScript, MongoDB, Vercel AI SDK with Gemini.
- **[SkillCellar](https://skillcellar.com).** A curated library of Claude Code skills with live GitHub stats. Next.js 16, Tailwind CSS v4, Drizzle, PostgreSQL, Stripe.
- **[andrei-design.ro](https://andrei-design.ro).** The site of my web studio. Static Next.js 16 with a scroll-driven canvas film on the homepage.
- **[VantagePrompt](https://vantageprompt.com).** A platform for optimizing and tracking AI prompts, with LLM-as-judge scoring. Laravel 12, React, Inertia.js, Gemini and OpenRouter models.
- **PHANTOM//LINK** (in progress). End-to-end encrypted messages that delete themselves on the first read or on a timer. The server holds only ciphertext, in memory. Bun, Hono, Svelte 5.

The source of these projects is private.
